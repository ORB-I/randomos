RandomOS

The most random OS without an RNG

Features / GitHub / License

Features

  • Mulitasking
  • FAT16
  • Dynamic ELF
  • PS/2 and USB-HID Keyboard and Mouse support
  • SATA support
  • Full dynamic memory management
  • Power state management
  • Ability to get time of day (via BIOS/CMOS)
  • High precision timing
  • Multiple framebuffer support
