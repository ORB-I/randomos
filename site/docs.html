1. System Call ABI

RandomOS utilizes the standard x86_64 syscall instruction for transitions between user space and kernel space. Parameters and system call numbers are passed via general-purpose CPU registers.

Register Convention

Register Purpose
RAX System call number (input) / Return value (output)
RDI Argument 0
RSI Argument 1
RDX Argument 2
R10 Argument 3 (replaces RCX, which is clobbered by the syscall instruction)
R8 Argument 4
R9 Argument 5

Return values: Non-negative values indicate success. Negative values represent error codes defined in errno.h (such as -EINVAL, -ENOMEM, -ENOEXIST).

3. User Utilities & Commands

Userland binaries reside in /bin/ and can be inspected via man <topic>:

  • sh: Interactive command shell with environment variables, PATH execution, and builtins.
  • ls [path]: Lists directory contents from EXT2 filesystem.
  • cat <file...>: Prints contents of specified files to standard output.
  • echo <args...>: Prints text arguments to standard output.
  • mkfile <file>: Creates a new empty file.
  • rm <file>: Deletes a file or directory.
  • clear: Clears the terminal screen buffer.
  • sleep <sec>: Pauses execution for specified number of seconds.
  • id / whoami: Prints real and effective user and group identities.
  • environ: Prints active environment variable table.
  • random: Reads and displays entropy from the kernel random generator.
  • login: Prompts for username and Argon2id password hash validation.
  • wm: Graphical window manager and desktop environment.
  • man <topic>: System manual documentation viewer.
  • reboot / poweroff: System power control utilities.

4. Configuration Files

/etc/passwd

Stores user accounts, credentials, and default configuration. Format is colon-delimited: 

username:argon2id_hash:uid:gid:homedir:shell
  • username: Login identifier.
  • argon2id_hash: Argon2id cryptographic hash (empty for passwordless login).
  • uid: Numeric user ID (0 for root).
  • gid: Numeric primary group ID.
  • homedir: Default starting directory upon login.
  • shell: Path to login executable (default: /bin/sh).

5. Graphical Subsystem & Window Manager

RandomOS provides multiple framebuffer support via create_fb() and switch_fb(). The window manager (wm) initializes a dedicated GUI framebuffer and implements double-buffered compositing to prevent screen tearing.

Built-in applications within the window manager include a graphical Terminal, File Browser, System Monitor, Notes editor, and Calculator.
