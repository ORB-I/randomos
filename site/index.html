About

RandomOS is an OS designed to be whatever the hell I want it to be because I'm tired of my dream to make a IEEE Std 1003.1 compliant OS. It's open source, MIT licensed, and as undocumented as Apple's APIs. RandomOS is a single-tasking OS because I'm too lazy to deal with the pain of writing a multitasking OS. It currently supports a very specific set of devices though more are planning on being added.

The Developers

RandomOS was started by me, @Wdboyes13 (William) in mid-2026 and recently also co-developed by @eskridd/@44tl (Eskrid). I expect to continue working on this OS for quite a while unlike most other projects I make. There is currently multiple updates daily as we add new features quickly without much planning.
