NAME
    syscalls - kernel system call interface

SYNOPSIS
    #include <sys/syscall.h>

DESCRIPTION
    RandomOS provides system calls via the x86_64 `syscall` instruction.
    Userland programs invoke these through libc wrapper functions or directly
    via __syscall0 through __syscall5.

SYSTEM CALL NUMBERS
    Number   Name               Arguments

    1        SYS_EXIT           int code

    3        SYS_WRITE          int fd, const void* buf, usize count
