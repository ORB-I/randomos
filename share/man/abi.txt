NAME
    abi - system call calling convention and register layout

DESCRIPTION
    RandomOS runs in 64-bit long mode on x86_64 processors. User applications
    invoke kernel services using the `syscall` instruction.

REGISTER CONVENTIONS
    Register    Role
    --------------------------------------------------------------------------
    RAX         System Call Number (input), Return Value (output)
    RDI         Argument 0
    RSI         Argument 1
    RDX         Argument 2
    R10         Argument 3 (replaces RCX, which is clobbered by syscall instruction)
    R8          Argument 4
    R9          Argument 5

RETURN VALUES
    The return value is passed in RAX.
    A non-negative value indicates success.
    A negative return value represents an error code defined in <core/errno.h>.

CLOBBERED REGISTERS
    The x86_64 `syscall` instruction clobbers RCX (stores RIP) and R11 (stores
    RFLAGS). All other userland general-purpose registers are preserved across
    the call.
